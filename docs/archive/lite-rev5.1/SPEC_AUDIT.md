## 4. Questions for the product owner

1. The skills win over [PRD](PRD.md) 8.13. Is it acceptable to put back `tokenVersion` with `change-password`/`logout-all` (L-1) and the `role`/`isActive` columns (L-2)? Or is there a constraint, such as build time, that makes you want to formally override the skill standard for this competition build?
2. At the venue, about how many people will use the demo at the same time from one Wi-Fi IP? This sets the env values for auth, join/preview and SOS throttles (findings #4, #5).
3. If a community's only admin is also its only member, may they leave, and should Lite allow deleting such a community? Today neither is possible (finding #21).
4. Should an admin be able to resolve an accepted SOS directly (ACCEPTED -> RESOLVED, skipping HANDLING), or is the HANDLING step mandatory as [PRD](PRD.md) 6.5 says (finding #8)?
5. Is the `JOIN_APPROVED` email part of the definition of done, or [STRETCH] (finding #24)?
